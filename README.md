## 📌 Sobre el proyecto

Sabores de la Plaza es un sitio web enfocado en conectar a los usuarios con la oferta de productos frescos y preparados de la plaza de mercado local. Ofrece una experiencia interactiva para explorar diferentes categorías de puestos (Fruver, Panaderías, Restaurantes, Heladerías), consultar tablas de precios y realizar pedidos en línea a través de formularios dedicados.

La aplicación está construida utilizando HTML5, CSS3 y Bootstrap 5, garantizando un diseño totalmente adaptativo (responsive), accesible desde cualquier dispositivo

---

## ✨ Características del proyecto

El sitio cuenta con diferentes secciones orientadas a presentación del colectivo gastronómico:

* 🏠 **Página Principal (Inicio):** Presentación del colectivo gastronómico con banner hero, carruseles de productos destacados y sección de preguntas frecuentes (FAQ) integradas.
* 🏬 **Catálogo de Puestos:** Visualización modular en tarjetas (Cards) de las distintas categorías del mercado.
* 📋 **Tabla de Precios:** Listado de productos con precios transparentes por unidad/cantidad.
* 🛒 **Sistema de Realización de Pedidos:** Formulario interactivo para que los clientes soliciten sus productos especificando el puesto, datos de contacto y detalles del pedido.
* 📱 **Diseño responsive:** adaptación a diferentes tamaños de pantalla.
* 🎨 **Interfaz visual:** diseño orientado a una navegación sencilla e intuitiva.

## 🖥️ Ejecutar el proyecto localmente

Como se trata de una plataforma web estática, puedes ejecutarlo directamente desde tu equipo.

### 1. Clonar el repositorio

```bash
git clone https://github.com/SneyderRodriguez/SABORES-DE-LA-PLAZA.git
```

### 2. Entrar al proyecto

```bash
cd SABORES-DE-LA-PLAZA
```

### 3. Ejecutar

Puedes abrir directamente el archivo:

```text
index.html
```

También puedes utilizar una extensión como **Live Server** en Visual Studio Code para ejecutar el proyecto mediante un servidor local.
